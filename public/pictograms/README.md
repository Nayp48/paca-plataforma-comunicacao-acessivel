# Pictogramas PACA

`symbols.svg` é um conjunto de pictogramas vetoriais desenhado para este projeto, sem recursos gráficos de terceiros. As formas e cores são originais e podem ser usadas, adaptadas e redistribuídas com o projeto PACA. Não há atribuição externa necessária.

Os desenhos são apoios visuais genéricos para comunicação. Eles não representam símbolos clínicos ou um padrão certificado de CAA. Sempre que possível, personalize cada item para corresponder à pessoa que o utiliza.
